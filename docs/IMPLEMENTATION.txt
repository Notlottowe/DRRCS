STORAGE AND ACCESS

The desktop client sends commands through the pages.dev API. The Python
Worker checks access and input, then reads or writes D1. The client does
not send SQL or keep a local incident database.

Updates use version checks. Record changes, history, and audit writes are
saved in the same D1 batch. A version conflict rolls back the batch.

Passwords have separate salts, PBKDF2-HMAC-SHA256 at 100,000 iterations,
and an HMAC step using a Worker-only pepper. Sessions expire after 30 minutes.
Only token hashes are stored in D1. Account status and roles are read again
for each protected request. Five failed logins cause a 15-minute cooldown.

Shelter managers and responders are restricted to their assigned records.
System Administrator is separate from operational roles. Public shelter
results exclude internal fields; private detail reads are audited.


BEHAVIOR TO KEEP WHEN EXTENDING THE PROJECT

Near Capacity starts at 90 percent. Over-capacity intake requires a warning
and a reason. Planned, Closed, and Temporarily Unavailable shelters cannot
accept occupancy changes.

Geographic boundaries are rectangles. Distance uses the haversine formula.
Route impact uses geographic containment/intersection rather than road routing.

Only Emergency Administrators can override open items when closing an incident.
At least one active System Administrator account must remain.

Draft notices do not take effect. Authorized notices record a result for each
recipient group. Failed groups can be retried. A server task checks scheduled
notices once a minute. Delivery is simulated.

Audit and history records are append-only. During an audit adapter outage,
events go to a queue and the System Administrator is alerted. Recovery keeps
the original event IDs. A complete D1 outage prevents the business write.

Unavailable dashboard sources are marked as unavailable. An operational
report with missing sections cannot be finalized. An incomplete after-action
report needs documented limitations before finalization.

Report incident selection uses creation times in [start, end). Shelter and
inventory totals are current snapshots. Finalized reports cannot be edited.
Text/JSON export copies an existing saved report to a local file.

test results, including inputs, expected outputs, actual outputs, and branches.
The tests use an isolated SQLite substitute for D1.

The terminal-specific check in that file belongs to the old client.
